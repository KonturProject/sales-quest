# Открытые вопросы

По правилу ТЗ (§0 п.3) открытый вопрос не выдумывается: реализуется через конфиг с дефолтом
отсюда. Когда автор требований отвечает — строка переезжает в «Закрытые» с датой, а решение
при необходимости записывается в [`DECISIONS.md`](DECISIONS.md).
