## Этап 2 — админка

- **«Долг» отрицательных шагов.** Команда на 5-й клетке, админ даёт −10 (показ 0), потом +3 — фигурка
  всё ещё на 0: шаги копятся ниже нуля. Так написано в FR-STEP-3; превью админки должно это показывать
  или обрезать сохраняемое значение.
- **Корректировка баллов** в форме админки — с полем «за какой день» (D-25).
- **Выдача и отзыв ачивки** в админке — с полем «за какой день / неделю» (`date`, D-29).
- **Состав из воронки — только активные.** В сентябрьской воронке заметная часть строк — люди без
  активности или с несколькими днями (уволенные, новички, не операторы). Если завести всех, план
  команд раздуется. Мастер первого состава предлагает тех, у кого есть показатели, остальных — списком
  «проверьте» (калибровка D-27).
- **Статистика ачивок** «сколько человек получили» (R-3 ТЗ) — для сверки порогов D-27 после первой игры.
- **Метки времени** админка пишет помощником `localTimestamp` (`src/data/time.ts`, D-11).
- **Запись данных** — `sealSeason` с `salt` и `reuse` (неизменные файлы остаются байт в байт, зрители
  не перекачивают их и не выводят ключ заново) + коммит через Git Data API (SEC-4).

## Этап 3 — сцена

Бюджет текстур панелей закрыт: 4 × 1024×559 WebP, ~12 МБ в GPU из 64.

- ~~Ворота на чекпоинтах~~ и ~~поворот героя~~ — сделаны в 3в (D-50).
- **Файлы героев** по 320–345 КБ: ключи анимаций и вершины без сжатия. Квантизация
  (`KHR_mesh_quantization`) и meshopt-сжатие уменьшат их вдвое-втрое, но meshopt требует декодера в бандле.
- **Стол — арт автора** (D-43): сейчас дерево процедурное; промпт — `docs/ART_BRIEF.md`.
- **«Змейка» 2×2** готова в запасе (D-42): включить — `BOARD_ARRANGEMENT = 'snake'` в `layout.ts`;
  перед этим посмотреть переход между рядами (одна длинная клетка над туманом) и рамку стола.
- **Обстановка вокруг стола** (D-43): стулья, бочки — в том же KayKit Dungeon Remastered (пак одобрен
  автором 10.10.2026, D-44): добавить файлы в `MODEL_SOURCES` и `npm run fetch-assets`, если захочет.
- **Декор — анимация** (D-44): облака небес и огонь факелов стоят; их можно качнуть той же переменной
  времени, что «жизнь» локаций (без лишних кадров).
- **2D-схема качает и 3D-код** (D-47): three.js — в начальном чанке, сцена не ленивая. Сделать `GameScene`
  ленивым — зрителям схемы и машинам без WebGL ~300 КБ меньше; начальный JS сцены вырастет на запрос чанка.
- **QA-6 в CI:** скриншот-тесты сравнивают только с эталонами этого ПК (win32); на Linux раннера они
  пропускаются. Эталоны Linux можно снять в CI (артефакт `--update-snapshots`) и закоммитить, если понадобится.
- **Отдельный шрифт HUD** (D-46): сейчас системный Palatino Linotype; «резной» свободный шрифт с
  кириллицей (например, Forum, лицензия OFL) — только по решению автора (OFL вне списка CC0/CC-BY) и после
  «да» на скачивание; ~40 КБ.
- **Предупреждение `THREE.Clock` устарел** в консоли — из R3F 9 с three 0.186; уйдёт с обновлением R3F.
