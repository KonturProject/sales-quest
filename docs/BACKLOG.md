# Отложенные задачи

Замечания и идеи, которые относятся к будущим этапам. При планировании этапа — пройтись по его разделу
и перенести пункты в план (или закрыть с причиной).

## Этап 1 — движок и данные

- **Проверка правил хука в CI** (ревью этапа 0). Хук не видит коммиты через GitHub API (админка
  этапа 2), `--no-verify` и клоны без `npm install`. Когда появится `data/`: в CI прогонять те же
  правила (`findViolations`) по диапазону пуша `before..sha`.
- **Проверять `*.enc.json` по содержимому, а не по имени** (ревью этапа 0): файл обязан быть
  конвертом `{v, alg, salt, iv, ciphertext}`; открытый JSON с именем `*.enc.json` сейчас прошёл бы.
- **Копирование `data/` в сборку** (DEP-2) — в Vite-сборке, чтобы локально и в CI было одинаково.

## Этап 3 — сцена

- **Выбор подхода к локациям** (D-23): «расписная доска» (ИИ-арт автора из `refs/` как текстура
  плоскости + 3D-персонажи и немного объёмных объектов) против сборки из CC0-наборов моделей.
  Учесть бюджет текстур (≤ 64 МБ в GPU, §12.1): 4 картинки 2048² без сжатия — ~85 МБ с мипмапами,
  значит 1024² или сжатые текстуры (KTX2/Basis).
- **Число клеток на локацию** (OQ-18): прогнать демо-месяц этапа 1 при 10 и 20 клетках, показать автору.

Сцена этапа 0 — заглушка; при переходе на перспективную камеру с пролётами (D-23):

- `MapScene`: проп `angles` читается только при монтировании — R3F 9 не пересоздаёт камеру,
  заданную объектом настроек, а плитки при этом повернутся. Камеру этапа 3 держать в своём
  компоненте-риге (ref на камеру, пересчёт при смене `ui.camera` и размера окна). `zoom` сейчас
  тоже фиксируется по ширине окна при монтировании; `lookAtOrigin` дублирует поведение R3F.
- `FrameCounter` считает тики цикла R3F, а не реальные отрисовки WebGL: при своём 30-FPS тикере
  (PERF-1) дополнительно отдавать `gl.info.render.frame`.
- `App` размонтирует канвас на любом другом маршруте. Лидерборд (`#/leaderboard`) должен
  накрывать сцену и замораживать её (PERF-6), а не пересоздавать WebGL-контекст и ассеты.
- `npm run size` считает начальный JS по `modulepreload`-ссылкам; при `build.modulePreload: false`
  он бы недосчитал. Надёжнее — `build.manifest: true` и обход статических `imports` точки входа.

## Когда-нибудь

- Закрепить GitHub Actions по SHA коммита, а не по тегу.
- Почта автора коммитов видна в публичной истории: для будущих коммитов можно перейти на
  адрес `…@users.noreply.github.com` (решает автор).
